# ULTRACRAFT REVOLVER — 3D Model

A first-pass, blocky 3D OBJ model based on the provided reference image: dark angular metal, neon-magenta energy strips, a chunky grip, barrel, cylinder block, and rear energy cell.

## Files
- `ultracraft_revolver.obj` — portable 3D geometry.
- `ultracraft_revolver.mtl` — dark-metal and neon-magenta materials.

## Open it
Import `ultracraft_revolver.obj` into Blender (File → Import → Wavefront (.obj)). Keep the `.mtl` file beside the OBJ so the material colors can load.

## Status and next steps
This is a visual blockout/reference model, not yet a Minecraft-ready item model or a verified in-game asset. The dimensions and hand pose need tuning in Blockbench/Blender, and the model needs conversion to the target Minecraft item format plus an inventory texture. The magenta material is a bright material color, not actual emissive lighting.

Design reference: the user-provided ULTRACRAFT REVOLVER first-person preview.
